# Oasis Infobyte Java Projects

This repository contains Java-based projects developed as part of the **Oasis Infobyte Internship**.  
The projects demonstrate **core Java concepts**, **object-oriented programming (OOP)**, and **problem-solving skills** through console-based applications.

## Projects
- ATM Management System  
- Online Examination System  
- Number Guessing Game  

## Technologies
- Java (Core Java)
- OOP Concepts
- Java Collections
- Console Input/Output
